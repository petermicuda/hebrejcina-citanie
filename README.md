# Hebrejčina – čítanie

Cvičenia na čítanie hebrejčiny podľa materiálov z hodín: lekcie 1–11, úvodné opakovanie, koncové písmená a dageš, podobné písmená, pravidlá čítania, Amida a všetky strany Big Practice.

- Výslovnosť je pod každým slovom, dá sa skryť a ťuknutím na riadok ukázať.
- Nočný režim, zväčšenie písma, obsah.
- Funguje aj bez internetu. V mobile: otvoriť v prehliadači → „Pridať na plochu“ / „Inštalovať aplikáciu“.
